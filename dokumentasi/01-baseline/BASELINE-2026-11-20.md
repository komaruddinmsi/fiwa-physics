## Kondisi situs

Beranda dan tiga aset aplikasi yang diperiksa memberi HTTP 200. Permintaan tanpa kuki login ke `katalog.json`, contoh metadata `konten/f-use/topik.json` dan contoh PDF e-book memberi HTTP 401. `GET /api/saya` memberi `{"siap":true,"masuk":false,"wajibKode":false}`. Ini menunjukkan pintu akun aktif untuk contoh jalur tersebut; tidak membuktikan seluruh otorisasi dan konfigurasi data telah lolos uji.

Pemeriksaan tampilan menggunakan sesi peramban yang sudah masuk, dalam mode guru. Beranda, jalur TKA, halaman topik F.USE dan jalur olimpiade berhasil menampilkan katalog. Tidak ada formulir dikirim, akun disetujui, nilai diberikan, jawaban disimpan secara sengaja, atau dokumen murid direset. Nama dan data murid tidak dikumpulkan untuk laporan.

Empat kartu jalur terlihat: IGCSE dan AS/A bertanda Segera hadir, TKA memuat dua topik, dan OSN memuat tiga topik. Teks pengantar beranda masih menyebut Tiga jalur meskipun empat kartu terlihat; ini ketidaksesuaian redaksi.

## Arsitektur yang terbaca

Antarmuka memakai HTML, CSS dan JavaScript tanpa framework aplikasi atau package manifest pada pohon yang diperiksa. `build.js` memindai struktur `konten/` dan menulis `katalog.json`. Sumber tahap dan bahan ajar terpisah dari folder aset bersama. `alat/` memuat generator Python dan bank soal; generator bukan bagian yang dijalankan dalam pemeriksaan ini.

Cloudflare Pages Functions menyediakan middleware akses statis serta API akun/progres. D1 menggunakan pengikat bernama `DB`; tanda tangan sesi memakai peubah `RAHASIA`. Kode menyediakan siswa, guru dan owner; registrasi serta login menggunakan surel dan kata sandi. Turunan kata sandi pada kode memakai PBKDF2-SHA256 100.000 putaran dengan garam acak, sedangkan sesi memakai tanda tangan HMAC. Pernyataan ini menjelaskan implementasi yang dibaca, bukan sertifikasi keamanan.

Progres mengikuti akun pada tabel D1 `progres`, dengan salinan lokal untuk antarmuka. Jawaban per dokumen berada di `lembar`; hubungan pembimbing ada di `bimbing`. Nomor epoch mencegah salinan murid yang usang mengembalikan hasil yang dibuka ulang guru. Panduan menjelaskan antrean nilai S8/S12 dan reset dokumen; alur tulis tersebut belum diuji ulang di produksi.

## Batas yang perlu dibawa ke update berikutnya

Dasbor Cloudflare, nama binding aktual, nilai rahasia, riwayat deployment, deployment ID, log runtime, isi D1 dan backup tidak diperiksa. Respons API mengindikasikan layanan siap, tetapi pengaturan build aktual dan commit deployment tidak dapat dipastikan hanya dari halaman publik. Empat berkas yang cocok dengan GitHub tidak membuktikan kesamaan seluruh deployment.

Pemeriksaan ini bukan uji ujung ke ujung terhadap login siswa, penyimpanan lintas perangkat, reset, penilaian, isolasi peran atau pemutaran semua media. Tampilan seluler, aksesibilitas menyeluruh, performa dan seluruh perhitungan soal juga belum diuji ulang. Angka hasil uji dalam log piloting tetap berstatus historis.

Repositori publik dapat dibaca di luar pintu login situs. Berkas guru dan bank sumber memang ada pada pohon publik; menyembunyikan tautan atau memakai hash di sisi peramban tidak menjadikan isinya rahasia. Middleware statis yang dibaca memeriksa sesi sah, belum membedakan peran untuk nama berkas `GURU_`; kebutuhan pemisahan bahan guru perlu diputuskan sebelum update akses berikutnya.
