# Pembersihan folder konten

Tanggal 21 November 2026. Pengguna meminta pembersihan khusus isi konten setelah pembersihan berkas alat/panduan.

96 HTML S1–S14 termasuk cabang S2b/S2c dan 10 HTML L lama dikeluarkan. Total konten berubah dari 277 menjadi 171 HTML: 156 halaman Physics TKA aktif dan 15 halaman paket lain. Semua 14 metadata JSON tetap dipertahankan. Seluruh 162 halaman keluaran edisi 3, termasuk enam bacaan di luar konten, tetap utuh.

build.js disesuaikan agar menemukan L interaktif tanpa bergantung pada index.html lama. Middleware mengalihkan tautan langsung S/L yang dihapus menuju rute aplikasi aktif. Kunci S pada status/API tetap diperlukan dan tidak dihapus. Halaman paket lain, media serta sumber materi aktif tidak diubah.

Nilai/isian akun tidak dihapus. Isian historis tidak otomatis tampil pada halaman baru; untuk format aslinya, pulihkan HTML terkait dari cadangan luar proyek. Pekerjaan ini hanya lokal dan belum diterbitkan.
