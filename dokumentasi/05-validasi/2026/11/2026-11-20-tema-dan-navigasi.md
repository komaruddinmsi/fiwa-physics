# Pemeriksaan pembaruan tema dan navigasi

16 pemeriksaan logika lulus pada 20 November 2026. Daftar terperinci berada di berkas JSON pendamping. Sintaks app.js dan tema.js juga diperiksa dengan Node.js.

Aturan status, gerbang, percabangan, penyimpanan, penilaian dan jadwal tidak berubah dibanding salinan sebelum edit. Urutan HTML panel kiri diuji untuk siswa baru, prasyarat gagal, prasyarat lulus, guru, tahap hilang dan bahasa Inggris. Tema diuji untuk nilai bawaan, pilihan tersimpan, penyimpanan peramban tidak tersedia, state tombol dan nama aksesibel, serta stylesheet iframe HTML lokal.

Pemeriksaan sidik berkas atas 238 sumber proyek awal menemukan hanya index.html dan assets/app.js berubah. Tidak ada berkas awal hilang; sumber konten dan layanan server tidak berubah.

Pemeriksaan visual desktop/ponsel, tinggi panel di peramban, seluruh PDF, aksesibilitas menyeluruh dan kontras pada semua dokumen tertanam belum terverifikasi. Koneksi pratinjau lokal ditolak oleh akses socket; permintaan izin ditolak otomatis. URL file ditolak kebijakan browser. Pratinjau mandiri disediakan untuk dibuka manual oleh pengguna, bukan dinyatakan sebagai uji yang telah lulus.

Tidak ada pengujian tulis terhadap akun, progres atau nilai produksi.
